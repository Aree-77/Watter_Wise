# Watter-Wise

موقع يحلل فاتورة الكهرباء أو المياه (بالصورة) باستخدام الذكاء الاصطناعي (Gemini)،
ويقارن الاستهلاك بالبيانات التاريخية، ويطلع خطة نصائح مخصصة لتقليل الفاتورة.



## هيكل المشروع

```
ai/            # استخراج بيانات الفاتورة + توليد خطة النصائح عبر Gemini
analysis/      # تحليل الاستهلاك مقارنة بالتاريخ + ربطها بخطة الـAI
templates/     # صفحات HTML (رفع الفاتورة + عرض النتيجة)
static/        # التنسيق (CSS)
data/          # فاتورة تجريبية + بيانات استهلاك تاريخية افتراضية
app.py         # نقطة تشغيل موقع Flask
```

## خطوات التشغيل محلياً

1. **ثبّت المكتبات** (تم تحديثها لتستخدم `google-genai` الجديدة بدل `google-generativeai`
   القديمة اللي توقف جوجل رسمياً عن دعمها):

   ```bash
   pip install -r requirements.txt
   ```

2. **ضع مفتاح Gemini API الحقيقي في ملف `.env`** (الملف موجود لكن المفتاح فاضي حالياً):

   ```
   GEMINI_API_KEY=ضع_مفتاحك_هنا
   ```

   احصل على مفتاح مجاني من: https://aistudio.google.com/apikey

3. **شغّل التطبيق:**

   ```bash
   python app.py
   ```

   افتح المتصفح على: http://127.0.0.1:5000

## الواجهة

الواجهة الآن صفحة واحدة فقط (Single Page):
- **قبل رفع أي فاتورة**: تظهر كروت الاستهلاك (كهرباء + مياه) بآخر قراءة مسجلة من
  البيانات التاريخية (`data/sample_data/consumption_history.csv`)، مع كرت رفع
  الفاتورة (بسيط: صورة فقط، بدون أي حقول إضافية).
- **بعد رفع الفاتورة**: نفس الصفحة تتحدث فورياً — الكرت المطابق لنوع الفاتورة
  (كهرباء أو مياه) يعرض المقارنة الحقيقية بالشهر السابق ونسبة التغيير، ويظهر
  كرت "التوفير الشهري المتوقع" وخطة التوصيات وتنبيه الاستهلاك غير الاعتيادي
  (إن وجد). الكرت الآخر (اللي ما انرفعت له فاتورة) يبقى يعرض "بانتظار الفاتورة".

الألوان والخطوط والتخطيط مطابقة لتصميم React الأصلي (`src/`) اللي سوّته زميلتك،
لكن مبنية بـ Flask/Jinja2 عادي بدل React عشان تشتغل مباشرة بدون خطوة بناء (build).

تم حذف حقول بيانات المنزل (عدد الأفراد، نوع المسكن، حديقة، مسبح) من الواجهة بناءً
على طلبك؛ خطة التوصيات الآن تُبنى على ملف تعريف افتراضي عام (`DEFAULT_HOME_PROFILE`
في `app.py`) بدل بيانات يدخلها المستخدم.

## وش تم إصلاحه

- **مشكلة "النسخة القديمة"**: مكتبة `google-generativeai` أوقف جوجل دعمها رسمياً
  ("All support for the `google.generativeai` package has ended"). تم الانتقال
  الكامل لمكتبة `google-genai` الجديدة في `ai/gemini_client.py`, `ai/extractor.py`,
  `ai/advisor.py`.
- **مشكلة "الموديل غير متاح" (404 NOT_FOUND)**: جوجل أوقفوا `gemini-2.5-flash` عن
  المفاتيح الجديدة. تم التحديث لـ `gemini-3.6-flash` (الموديل المستقر الحالي، آخر تحديث
  يوليو 2026). إذا جوجل غيّرت الموديلات مرة ثانية مستقبلاً، غيّر القيمة في
  `MODEL_NAME` داخل `ai/gemini_client.py` فقط — كل باقي الكود ما يحتاج تعديل.
- تم حذف معاملات `temperature`/`top_p` القديمة (جوجل ألغتها بدءاً من Gemini 3.x
  وأصبحت تُتجاهل، وقريباً بترجع خطأ HTTP 400). البديل المعتمد من جوجل: الاعتماد على
  `system_instruction` لضبط الدقة، و`thinking_level` بدل الإعدادات القديمة.
- تم فرض إخراج JSON مباشر من الموديل (`response_mime_type`) لتقليل احتمال فشل التحليل.
- تم إكمال `analysis/savings.py` الفاضي، ليربط تحليل الاستهلاك بخطة توصيات الـAI.
- تم حذف كود اختبار كان يشتغل تلقائياً عند استيراد `analysis/water.py`.
- تم بناء واجهة Flask كاملة (`app.py`, `templates/`, `static/`) من الصفر.
